# PawsCamp On-site PromptPay Edition

เวอร์ชันนี้ออกแบบให้ลูกค้าจองรถในแอป แต่ชำระเงินจริงหน้างาน

## Flow
1. ลูกค้าจองรถ
2. คนขับรับงาน
3. คนขับไปรับน้องหมา
4. ส่งถึงปลายทาง
5. ลูกค้าเลือก:
   - สแกน PromptPay หน้างาน
   - เงินสดหน้างาน
6. คนขับตรวจยอดเงินจริง
7. คนขับกด "ยืนยันรับเงินแล้ว"
8. Booking เปลี่ยน paymentStatus = paid
9. ลูกค้าดูใบเสร็จในแอปได้

## ข้อดี
- ไม่ต้องต่อ Payment Gateway
- ไม่ต้องสมัคร Merchant Gateway ก่อน
- เริ่มใช้งานได้เร็ว
- ลดความซับซ้อนด้านระบบชำระเงิน

## ข้อจำกัด
- ระบบตรวจเงินเข้าอัตโนมัติไม่ได้
- คนขับต้องตรวจยอดในแอปธนาคาร/บัญชีเอง
- ปุ่มยืนยันรับเงินเป็น manual confirmation

## สิ่งที่ควรทำก่อนเปิดใช้งานจริง
- เปลี่ยน PromptPay ID ตัวอย่างเป็นเบอร์/เลขนิติบุคคลจริง
- ทำ QR PromptPay จริงจากข้อมูลบัญชีของธุรกิจ
- เพิ่มสิทธิ์ role ให้เฉพาะคนขับกดยืนยันชำระ
- ทำ audit log ว่าใครกดยืนยัน เมื่อไร
- เพิ่มเลขใบเสร็จ/เลขที่เอกสาร
- เพิ่ม Privacy Policy และ Terms
